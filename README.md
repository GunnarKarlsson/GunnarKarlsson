## Hi there 👋

I'm Gunnar Karlsson, software developer. I work mostly with Rust and Android/Kotlin, and sometimes web. 

## Things I've built:

* [Android dashboard](https://github.com/GunnarKarlsson/android-dashboard) - an ai-powered dashboard tool for debugging Android apps.

* [Sportanalytics](https://github.com/GunnarKarlsson/sportanalytics) - a Rust crate for easy generation of metrics for running and cycling.

* [AndroidCryptoWallet](https://github.com/GunnarKarlsson/AndroidCryptoWallet) - An Android cryto wallet with support for Bitcoin and EVM-based tokens including Ethereum.
